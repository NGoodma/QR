# Telegram QR Bot

Присылаешь боту ссылку или любой текст, бот спрашивает формат, стиль и цвет и присылает QR-код файлом. На каждом шаге, кроме первого, есть кнопка «← Назад»: она отменяет последний выбор.

1. Ссылка или текст. Если в сообщении две строки, похожие на название сети и пароль Wi-Fi (пароль 8–63 символа, название до 32 байт), бот спрашивает: **📶 Код для подключения к Wi-Fi** или **📝 Просто текст**. Код для Wi-Fi записан в формате `WIFI:T:WPA;S:…;P:…;;`: камера телефона по нему сама предлагает подключиться к сети. Если пришёл текст, который не ссылка и не Wi-Fi, бот в том же сообщении с выбором формата подсказывает, что для Wi-Fi нужно прислать название сети и пароль двумя строками. Отдельного шага для этого нет.
2. «Выберите формат»: **JPG**, **PNG** или **SVG**.
3. «Выберите стиль точек»: квадратные, скруглённые или круглые. У круглых три больших угловых квадрата остаются скруглёнными: угловые квадраты из точек не читают некоторые сканеры.
4. «Выберите цвет»: чёрный, белый, красный, оранжевый, жёлтый, зелёный, синий, фиолетовый, коричневый или **🎨 Свой цвет (HEX)**.
5. Дальше:
   - **PNG** и **SVG** приходят сразу, на прозрачном фоне. SVG векторный: бот рисует его сам одним `<path>`, теми же фигурами, что и PNG (тест сверяет их попиксельно);
   - для **JPG** бот спрашивает «Выберите цвет фона» (те же цвета, кроме цвета кода, и тоже со своим HEX), потом присылает файл.

### Свой цвет (HEX)

Кнопка «🎨 Свой цвет (HEX)» присылает сообщение «Пришли HEX-код цвета…» с `force_reply`: Telegram сам ставит ответ на него, человеку остаётся набрать `#ff8800` и отправить. Подходят `#FF8800`, `ff8800`, `#f80`. Бот удаляет подсказку и продолжает с того же места: меню выше меняется на следующий вопрос, либо приходит готовый файл. Если код непонятный или совпадает с цветом кода, бот просит прислать ещё раз. HEX, присланный без подсказки, бот не принимает и подсказывает нажать кнопку.

Памяти у бота по-прежнему нет. Ответ на сообщение приходит вместе с самим сообщением, поэтому подсказка несёт всё нужное: выбор и номера сообщений лежат в `#фрагменте` ссылки «Подобрать цвет» (она ведёт на htmlcolorcodes.com; фрагмент браузер на сайт не отправляет), а текст пользователя лежит в свёрнутой цитате. Свои цвета хранятся в `callback_data` как 6 цифр без `#`, например `q:t:jpg:rd:123456:white`. Предупреждения о читаемости работают и для своих цветов.

Текст влезает до 2300 латинских букв или около 1100 русских, длиннее бот не берёт. С версии 25 (примерно от 600 символов) бот предупреждает, что код плотный.

Если сочетание плохо сканируется, бот добавляет к файлу предупреждение. Так бывает, когда код светлый на тёмном фоне, когда цвета в оттенках серого различаются меньше чем на 80 из 255 (BT.601) или когда светлый код на прозрачном фоне (PNG, SVG). Тест проверяет каждое сочетание цветов без предупреждения во всех стилях и с разными текстами сканером ZXing, а все стили и форматы ещё и OpenCV (SVG перед этим переводится в картинку через resvg). Порог 80 подобран по замерам: формула контраста WCAG пропускала, например, фиолетовый на красном, который не читается.

Бот ничего не хранит. Меню отправляется ответом на сообщение с текстом, поэтому при каждом нажатии текст берётся из `reply_to_message`, а выбор хранится в `callback_data`: `q:<тип>:<формат>:<точки>:<цвет>:<фон>`, ещё не выбранные поля пустые, например `q:t:jpg:ci::`. Кнопка HEX: то же с префиксом `x:`. Кнопка «Назад» несёт то же состояние без последнего выбранного поля.

## Хостинг

Vercel Hobby, бесплатно: Python-функция `api/telegram.py` принимает webhook от Telegram по адресу `https://qr-ngoodma.vercel.app/api/telegram`. Секрет webhook выводится из токена бота (SHA-256), поэтому отдельный секрет хранить не нужно. Как завести аккаунт и токены, описано в [docs/vercel-setup.md](docs/vercel-setup.md).

GitHub Actions (`.github/workflows/deploy.yml`) запускается на каждый push:
- `pytest`;
- в `main`, если заданы секреты `VERCEL_TOKEN` и `TELEGRAM_BOT_TOKEN`, запускает `scripts/deploy.py`: проект, переменная окружения, отключение защиты, деплой, адрес, webhook.

Скрипт можно запускать сколько угодно раз.

## Разработка

```bash
python3 -m venv .venv
```

```bash
.venv/bin/pip install -r requirements.txt pytest opencv-python-headless zxing-cpp resvg-py
```

```bash
.venv/bin/python -m pytest -q
```

Тесты подменяют Telegram и проверяют все шаги, Wi-Fi, форматы, прозрачность PNG, цвет фона JPG, SVG, кнопки «Назад», свои HEX-цвета, подсказку про Wi-Fi, предупреждения и то, что картинки реально сканируются (OpenCV, ZXing и resvg для SVG; без них эти тесты пропускаются).
