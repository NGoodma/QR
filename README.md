# Telegram QR Bot

Присылаешь боту ссылку, бот спрашивает формат и цвет и присылает QR-код файлом.

1. Ссылка → «Выберите формат»: **JPG** или **PNG**.
2. «Выберите цвет»: чёрный, белый, красный, оранжевый, жёлтый, зелёный, синий, фиолетовый, коричневый.
3. Дальше:
   - **PNG** приходит сразу, на прозрачном фоне;
   - для **JPG** бот спрашивает «Выберите цвет фона» (те же цвета, кроме цвета кода), потом присылает файл.

Если сочетание плохо сканируется (светлый код на тёмном фоне, почти одинаковые цвета, светлый PNG), бот добавляет к файлу предупреждение. Все сочетания без предупреждения проверены сканером OpenCV.

Бот ничего не хранит. Меню отправляется ответом на сообщение со ссылкой, поэтому при каждом нажатии ссылка берётся из `reply_to_message`, а выбор хранится в `callback_data` (`f:jpg` → `c:jpg:black` → `b:black:white`).

## Хостинг

Vercel Hobby, бесплатно: Python-функция `api/telegram.py` принимает webhook от Telegram по адресу `https://qr-ngoodma.vercel.app/api/telegram`. Секрет webhook выводится из токена бота (SHA-256), поэтому отдельный секрет хранить не нужно. Как завести аккаунт и токены, описано в [docs/vercel-setup.md](docs/vercel-setup.md).

GitHub Actions (`.github/workflows/deploy.yml`) запускается на каждый push:
- `pytest`;
- в `main`, если заданы секреты `VERCEL_TOKEN` и `TELEGRAM_BOT_TOKEN`, запускает `scripts/deploy.py`: проект, переменная окружения, отключение защиты, деплой, адрес, webhook.

Скрипт можно запускать сколько угодно раз.

## Разработка

```bash
python3 -m venv .venv
```

```bash
.venv/bin/pip install -r requirements.txt pytest
```

```bash
.venv/bin/python -m pytest -q
```

Тесты подменяют Telegram и проверяют все шаги, форматы, прозрачность PNG, цвет фона JPG и предупреждения.
